# IBM Data Analyst Professional Certificate Capstone Project

## 📌 Project Overview
This repository contains the end-to-end capstone project completed as the final requirement for the **[IBM Data Analyst Professional Certificate](https://www.coursera.org/professional-certificates/ibm-data-analyst)** on Coursera. 

In this capstone, I assumed the role of an **Associate Data Analyst** at an IT consulting firm. My objective was to analyze real-world tech ecosystem data to identify **emerging technology trends, in-demand programming languages, database requirements, and salary distributions**. The insights derived from this analysis assist organizations and developers in making data-driven training, recruitment, and upskilling decisions.

---

## 🛠️ Tech Stack & Tools
* **Programming Language:** Python 3
* **Data Collection:** Web Scraping (BeautifulSoup), REST APIs (`requests`)
* **Data Wrangling & EDA:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Dashboards & BI:** IBM Cognos Analytics / Looker Studio
* **Environment:** Jupyter Notebooks, GitHub

---

## 🔄 Data Analytics Lifecycle & Methodology

### 1. Data Collection
________________________
* **Web Scraping:** Gathered data from tech job postings and industry wikis using Python libraries.
* **API Extraction:** Fetched dynamic labor market and stack demand data through RESTful API endpoints.
* **File Handling:** Ingested large-scale surveys (including the Stack Overflow Developer Survey dataset) from CSV and Excel formats.

### 2. Data Wrangling & Cleaning
_________________________________
* Normalized nested structures and structural survey schemas.
* Identified and handled missing/null values systematically.
* Detected and removed duplicate records to ensure analysis integrity.
* Outlier detection using IQR (Interquartile Range) methods to filter extreme salary skewing.

### 3. Exploratory Data Analysis (EDA)
________________________________________
* Analyzed demographic distributions (age, gender, geography) against professional tech choices.
* Evaluated median salary metrics grouped by experience levels and specialized roles.
* Computed correlation matrices to discover overlapping technology frameworks.

### 4. Data Visualization & Dashboarding
* Created tailored visual plots (bar charts, scatter plots, bubble charts, and pie charts) to communicate technological distribution.
* Developed an interactive, multi-tab **IBM Cognos Analytics Dashboard** to allow stakeholders to dynamically filter technology sectors.

---

## 📊 Key Insights & Summary Findings
__________________________________________
* **Language Dominance:** Python and SQL remain the baseline prerequisites across mainstream data and development tracks, with JavaScript dominating full-stack frameworks.
* **Database Shift:** Relational options like PostgreSQL and MySQL maintain massive footprints, while MongoDB leads modern NoSQL adoption trends.
* **Web Frameworks:** High demand converges around React.js and Node.js for modern application deployment portfolios.
